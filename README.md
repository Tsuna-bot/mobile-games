# Mobile Games

Jeux web mobiles en 3D, jouables directement dans le navigateur.

| Jeu | Description |
| --- | --- |
| [Neon Drift](neon-drift/) | Arcade 3D néon à une main (Three.js) : glisse, esquive, frôle. |
| [Aetherfall](archer/) | Roguelite d’aventure 3D style anime (Three.js, héros VRoid, monstres Quaternius et KayKit) dans l’esprit d’Archero : cours pour esquiver, arrête-toi pour tirer. 8 mondes en paysages ouverts, 5 héros, 25 capacités, 8 boss, équipement, fusions, talents, familiers. |
| [Bastion](tower-defense/) | Tower defense 3D (Three.js, modèles Kenney) : 5 niveaux, Survie, Royaume en monde ouvert (récolte, construction, jour/nuit), 12 tours, 6 sorts, boutique, succès, sauvegarde automatique. |

Chaque jeu est un dossier statique autonome, sans étape de build. Voir le README de chaque jeu pour le lancer, le tester sur téléphone et le déployer.
